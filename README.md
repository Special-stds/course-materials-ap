## 🎯 Course Goals

The course focuses on developing students' ability to:

* Write clean, readable, and maintainable Python code
* Understand advanced Python programming concepts
* Apply Object-Oriented Programming principles
* Design and organize larger Python programs
* Use functions, modules, and packages effectively
* Work with Python data structures
* Handle files and external data
* Handle errors and exceptions properly
* Understand and apply software design principles
* Debug and test Python programs
* Use Git and GitHub for software development
* Develop problem-solving and algorithmic thinking skills
* Work on practical programming projects
* Develop independent programming and research skills

---

## 🐍 Python

Python is the primary programming language used throughout this course.

Students will learn how to move from writing simple scripts to designing structured and maintainable Python applications.

The course emphasizes both **programming concepts** and **practical software development**.

---

## 📖 Topics

The course will cover topics including:

### Python Fundamentals

* Python syntax and programming concepts
* Variables and data types
* Conditional statements
* Loops
* Functions
* Strings
* Lists, tuples, sets, and dictionaries

### Advanced Functions

* Function arguments
* `*args` and `**kwargs`
* Lambda functions
* Higher-order functions
* Scope and namespaces
* Recursion

### Object-Oriented Programming

* Classes and objects
* Constructors
* Instance and class attributes
* Methods
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Composition

### Python Modules & Packages

* Import system
* Creating modules
* Creating packages
* Package structure
* Reusable code
* Virtual environments
* Dependency management

### Exception Handling

* Exceptions
* `try` / `except`
* `else` / `finally`
* Raising exceptions
* Custom exceptions
* Writing robust programs

### Files & Data

* Reading and writing files
* Working with CSV files
* JSON
* Data serialization
* Working with structured data

### Advanced Python Features

* Iterators
* Generators
* List and dictionary comprehensions
* Decorators
* Context managers
* Type hints
* `dataclasses`

### Software Development

* Code organization
* Clean code principles
* Debugging
* Testing
* Project structure
* Documentation
* Dependency management

### Git & GitHub

Students will also learn how Git and GitHub can be used as part of the software development workflow.

Topics include:

* Git fundamentals
* Repositories
* Commits
* Branches
* Merging
* Pull Requests
* Code collaboration
* GitHub repositories
* Project submission workflow
